# 分析：B群10点の物理的分離構造（バッチ13）

**分析日：2026-08-28 ／ OSM基準：`kanto-260801.osm.pbf`（2026年8月1日固定）**

## 0. 結論

- 対象は、旧方式で検出された16way・18点に含まれるB群7way・8点と、現行方式で新規に検出されたB群2way・2点の、**計9way・10点**である。
- 10点中9点で、OSM上に別wayの対向車線候補が存在し、両wayの`name`も一致した。例外P05は、同名の対向wayではなく、無名の`tertiary_link`と並走する「旧海岸通り」の組合せだった。
- 判定点付近の中心線間隔は、対向wayがある9点で6.862–12.723mだった。誤対応先wayと進行方向の角度差はP02の133.7°を除き169.4–180.0°で、ほぼ逆向きだった。
- 対象道路way自体の`dual_carriageway=*` / `divider=*`は0/10点だった。周辺20mの検索ではP02・P11・P14の**3/10点**に`barrier`または`railway`の分離関連タグがあった。したがってタスクC-2の「OSM上で分離構造を示すタグが確認できた点」は3/10点と数える。ただし、固定PBFだけでは各地物が実際に対向車線間を分けているか確定できない。
- よって、**分離wayというデータ表現の存在は9/10点、周辺の分離関連タグは3/10点で確認できた。** 具体的な物理構造との因果は人による目視記入後に確定する。

## 1. 方法と出典

分析専用スクリプト `bicycle-navi/backend/scripts/analyze_b_group_separation.py` で固定PBFを走査した。判定ロジックは変更していない。

- 点とwayの距離：現行判定と同じ有限線分距離
- 中心線間隔：判定点に最も近い誤対応先way上の点から、対向wayまでの局所最短距離
- 角度差：現行rank1の点は採点時の`diag_angle_deg`、旧方式でのみ対象wayだった点は前後サンプル点と局所線分から再計算
- 分離タグ：対象2way上の`dual_carriageway` / `divider`等、および判定点から20m以内の`barrier` / `landuse` / `railway`等
- 明細：`bicycle-navi/backend/data/b_group_separation_evidence.csv`、周辺候補：`bicycle-navi/backend/data/b_group_separation_features.csv`

## 3. 仮説への含意

### 3.1 確認できたこと

別wayの対向車線候補が9/10点にあり、その9点では名称も一致した。中心線は約6.9–12.7m離れ、誤対応先の方向はほぼすべて走行方向と反対だった。この結果は、B群の大部分が「上下線を別wayとして表すOSMの道路モデル」と密接に関係することを支持する。

P14ではOSM上にも近傍の`barrier=hedge`があり、確認者の「植栽・生垣のようなものが間にある道路がB群になりがち」という観察と整合しうる。ただし、実際に対向車線間にあるかは目視記入で確認する。

### 3.2 まだ確認できないこと

別wayであること自体から、中央分離帯・植栽・柵等の**具体的な物理構造が必ず存在する**とは断定しない。OSMでは表現上の理由や接続構造でもwayが分割されうる。またP05は同名対向wayの型に入らず、無名ランプと並走本線の局所配置である。

したがって「B群10点すべてが物理的分離構造によって生じた」という仮説は、各検証記録の空欄を人が埋めるまで未確定である。

## 4. 限界2の書き換え案（記入完了後に確定）

> **限界2：物理的分離道路におけるデータモデル間の表現差**
> OSMでは、上下線が中央分離帯・植栽・柵・軌道等で物理的に分離された道路を別々のwayとして表現する。一方、外部サービスから得るルートpolylineは、OSMの各車線中心線と同じ表現粒度・位置を持つとは限らない。この差がある地点では、polyline点が本来の走行wayより対向側wayに近づき、逆方向の`oneway=yes`へ誤対応して偽陽性を生じうる。本研究のB群10点では9点に別wayの対向車線候補を確認した。ただし、具体的な物理的分離構造は目視記録の記入完了後に確定する。
>
> この原因説明は、距離指標だけでは解けないという既存結論を変更しない。残存2点では、Googleのpolyline点が実際に誤ったway上または近傍（0.346m、1.399m）にあり、推定される正しいwayは5m以上先にある。したがって有限線分距離へ変更しても解けず、進行方向整合または経路連続性が必要である。データモデルの差異は「なぜ距離だけでは正しいwayを選べないか」を説明する上位要因として接続する。

この案は**人による分離構造欄の記入完了後に確定**する。目視結果がOSMタグと食い違う点は、その不一致自体を記録する。
