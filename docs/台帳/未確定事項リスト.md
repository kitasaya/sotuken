## 執筆中の禁止チェック

- [ ] 未確定事項を「今後確認する予定」なしに確定形で書いていないか
- [ ] 幾何的診断済みとストリートビュー画像による目視確認済みを混同していないか
- [ ] タグ基準Recall 1.000を現地基準の検出精度と呼んでいないか
- [ ] d1最小値を地図同士の正解対応誤差と呼んでいないか
- [ ] 未取得の小金・conflation文献を二次情報から要約していないか
- [ ] 通行禁止違反の事故件数・青切符件数を推定していないか
- [ ] R1（本システムの提示ルート）の違反数を、測定済み14/15ペアの限定なしに書いていないか
- [ ] `system_violation_count` を「提示ルートに残る違反数」として書いていないか（リルート前の値である）
- [ ] 「違反を排除する」の対象を一方通行に限定しているか（Layer 2 は案内のみ）
