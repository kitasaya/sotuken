## 2. この論文が実際に主張していること

### 2.1 問題設定

- わが国の自転車交通事故の約8割が交差点で発生している（PDF p.1, p.6）。
- 内閣府報告書ベースで、自転車関連事故156,495件に対し交差点106,178件（68%）、交差点付近7,604件を含めると**73%**が交差点および交差点付近（PDF p.1、文献2）。
- 警視庁交通局ベースで、平成30年の自転車関連事故85,641件のうち、出会い頭43,232件・左折時12,025件・右折時11,358件の3類型が**77.8%**（PDF p.1、文献1）。
- 対策のうちソフト対策（安全運転教室・啓蒙）は「その効果は十分に検証がなされているとはいいがたい」（PDF p.1）。

### 2.2 提案するアプローチ

> 自転車運転者に対して規制したり罰したりするのではなく、自転車運転者が自発的に交差点で一旦停止することで事故を防ぐ（PDF p.1 要旨）

- 王立カナダ騎馬警察隊の「ポジティブチケット」を参照し、ゲーミフィケーションを組み合わせた（PDF p.2、文献4・5）。
- スマホの加速度センサとGPSで交差点内の停止を検知し、ポイントを付与するアプリを開発した。

### 2.3 判定ロジック（PDF pp.2–3）

| 項目 | 内容 |
|---|---|
| 対象交差点 | 尼崎市のDRM（道路情報データ）上、幅員2.5m以上の道路に交差する道路の交差点 **4,044か所**、加えて市内**11か所**の踏切 |
| 信号・優先道路 | **考慮しない**（停止して安全確認すること自体を目的とするため） |
| ポイント付与範囲 | 交差点中心から**半径20m以内** |
| 停止判定 | 加速度センサのX・Y・Z の**3軸すべてで2秒間の挙動停止** |
| 通信間隔 | 2秒ごと。2秒の停止は必ず通信タイミングに含まれる |
| 不停止判定 | 2秒ごとの通信時に交差点に入域し停止していなければ「不停止交差点（通過交差点）」と判定 |
| 再付与の制限 | 同一交差点では前回付与から所定時間（尼崎では**2時間**）経過するまで付与しない |
| 自転車乗車中判定 | GPS 2点間から時速10〜15kmを乗車中とする仕様だが、**本実証実験では未実装** |

### 2.5 報告されている「効果」とその測定方法（PDF p.5）

**論文が成果として報告しているのは、付与ポイント数と停止・通過回数の実績値だけである。**

| 指標 | 値 |
|---|---|
| 総ポイント付与数（151日間） | **10,890ポイント**（102名が計10,890回交差点で停止したことに相当） |
| 1人あたり | 約107ポイント |
| 1日あたり | 約72ポイント（72.1） |
| 2018年11月〜2019年2月末（120日） | 7,745ポイント、1日あたり**64.5** |
| 2019年3月のみ（31日、賞品キャンペーン期間） | 3,145ポイント、1日あたり**101.5**、1人あたり約65ポイント |
| 実験期間中の交差点での停止回数 | **12,025回** |
| 実験期間中の通過（不停止）回数 | **48,667回**（停止回数の**4.0倍**） |
| 停止交差点 上位1位 | 272回 |
| 通過交差点 上位1位 | 436回 |

**測定方法上、極めて重要な点：**

1. **介入前後の比較がない。** アプリ導入前の停止率、および非利用者の停止率は測定されていない。対照群もベースラインも存在しない。
2. したがって、**「自発的な一旦停止を促した」ことの効果は定量的に示されていない。** 報告されているのはアプリ利用中の停止・不停止の絶対回数だけである。
3. 停止回数と付与ポイント数が一致しないことは論文自身が述べている（「停止してもポイント付与条件を満たしていない場合がある」PDF p.5）。したがって10,890ポイントを「10,890回停止した」と読み替える論文自身の記述には、内的なずれがある。
4. 論文は「効果」という語で成果を主張していない。第5章は「今後の展望」であり、事故削減効果の測定は行われていない。

**論文が示していないが本文の数値から内的に導ける事実：**

> 実験期間中、アプリが検知した交差点入域は 12,025 + 48,667 ＝ 60,692回であり、そのうち停止と判定されたのは 12,025回、**19.8%**である。すなわちアプリ利用中でも、交差点入域の約8割は不停止だった。

この計算は本文の2つの数値から直接導ける。論文はこの比率を提示していない。**引用する場合は「本研究による再計算」であることを明記すること。**

### 2.6 論文自身が挙げる課題（PDF p.5）

システム側：再付与設定時間、交差点範囲の設定、交差点抽出条件、ポイント反映のタイムラグ、走行速度による判定誤差、消費電力、タイマー・バックグラウンド機能の操作性、ランキング機能の設置。

ビジネスモデル側：キャンペーン期間外は「単にポイントが貯まるだけ」であり、商業施設等との連携が未実現であること。

## 3. 精読で発見した問題点

| # | 問題 | 詳細 |
|---|---|---|
| 1 | **効果検証の設計がない** | 前後比較・対照群・ベースラインのいずれもない。「自発的な一旦停止を促す」という介入の効果は、本論文では検証されていない |
| 2 | **賞品効果と時期効果が交絡している** | 1日あたりポイントが64.5→101.5へ増えたのは3月のキャンペーン期間だが、iOS版が2月18日リリースで利用者が増えた直後であり、季節要因も分離されていない。論文はこの交絡に言及していない |
| 3 | **ポイント数と停止回数の混同** | p.5で総ポイント10,890を「102名が合計10,890回交差点で停止した」と述べる一方、同じ段落で停止回数は12,025回としており、両者が一致しない理由を「付与条件を満たさない場合がある」とだけ説明している |
| 4 | **停止率が示されていない** | 12,025回と48,667回という分子・分母に相当する数値を提示しながら、停止率（19.8%）を計算していない |
| 5 | **参加者の代表性** | 全DL 390のうち属性無回答が多い（性別無回答160、職業無回答161、利用目的空欄131）。属性別分析の分母が不安定 |
| 6 | **統計的検定なし** | 全編を通じて有意差検定・信頼区間は示されていない |
| 7 | **⚠️ 停止回数12,025が p.1の事故統計と同一の数値** | p.1では平成30年の「左折時衝突12,025件」、p.5では「実証実験期間中の交差点で停止した全回数は12,025回」。**同一の値が別の文脈で現れている**。p.5の 48,667 ÷ 12,025 ＝ 4.047 は本文の「4.0倍」と整合するため、p.5内部では自己整合している。しかし偶然の一致か転記誤りかは本文からは判別できない。**停止回数を引用する場合はこの点を注記すること** |
| 8 | **同一文中で3つの分母が混在** | p.4「全DLでは男性146（37.4%）、女性84（21.5%）であるが、全ユーザは男性60（41.1%）、女性32（38.1%）、コアユーザでは男性23（47.9%）、女性21（43.7%）」。前半の分母は390、中盤は各性別の全DL数（146・84）、後半は48であり、同一文中で分母が3回変わる |

いずれも「概要」を報告する論文としては想定内の範囲であり、論文の瑕疵として糾弾する性質のものではない。**引用時に「効果が実証された」と書かないために必要な確認事項である。**

## 4. 現在の引用意図との照合

### 4.1 現在の引用意図

`RESEARCH.md` §5.4：

> 行動変容によるアプローチの先行事例。（中略）本研究は「システム側が違反経路を排除する」アプローチであるのに対し、今田らは「利用者の自発的行動を促す」アプローチである。この対比は、第VII部で論じる「経路で排除できない法規（一時停止等）への対応方針」の議論に接続できる。

`docs/文献/文献リスト_統合版.md` 2-9：

> 引用箇所：**行動変容アプローチとの対比**（類型C＝一時停止等への対応方針の議論）

### 4.2 照合結果

**引用意図と本文は一致している。ズレは見つからなかった。**

- 「規制したり罰したりするのではなく、自発的に一旦停止することで事故を防ぐ」は論文の要旨そのままであり、行動変容アプローチとしての位置づけは正確である。
- 「事後的な行動変容の促進」対「事前排除」という対比も成立する。今田らのアプリは走行後・走行中の行動に対してポイントを付与するのに対し、本研究はルート生成の段階で違反エッジを除外する。介入のタイミングが異なる。
- 一時停止（Layer外）への対応方針の議論に接続できるという位置づけも妥当である。今田らが対象とした「交差点での一旦停止」は、まさに本研究がLayer 1・Layer 2のいずれでも扱えないと整理した法規である。

### 4.3 ただし追加で必要になる限定

**「今田らは行動変容の効果を実証した」とは書けない。** 実証されているのは、アプリが動作しポイントが付与されたこと、および参加者の属性分布までである。停止行動の変化は測定されていない。

正確な限定を付した記述は次のとおり。

> 今田ら（2020）は、交差点での一旦停止に対してポイントを付与するスマートフォンアプリを開発し、2018年11月1日から2019年3月31日までの151日間、兵庫県尼崎市で実証実験を行った。参加者は全ダウンロード390名、1ポイント以上を獲得した利用者102名である。期間中に付与されたポイントは10,890、検知された交差点での停止は12,025回、不停止は48,667回であった。ただし同研究は介入前後の比較や対照群を設けておらず、一旦停止行動が実際に増加したかは測定されていない。

## 5. 正確に引用するための文案

### 5.1 アプローチの対比として引用する場合

> 交通法規への対応には、走行後・走行中の行動へインセンティブを与えて行動変容を促す方法と、経路生成の段階で違反を排除する方法がある。前者の例として今田ら（2020）は、交差点で一旦停止するとポイントが付与されるスマートフォンアプリを開発し、兵庫県尼崎市で5か月間の実証実験を行った。同研究は「規制したり罰したりするのではなく」自発性を喚起する設計思想を明示している。本研究はこれとは異なり、通行禁止違反となる経路をルート探索の段階で除外する。両者は介入のタイミングが異なり、対象とする法規も異なる。

### 5.2 経路で排除できない法規の議論で引用する場合

> 一時停止義務のように、経路の選択によっては回避できない法規が存在する。本研究のLayer 1（経路除外）およびLayer 2（走行案内）は、いずれもこの類型を扱えない。今田ら（2020）が交差点での一旦停止をポイント付与の対象としたのは、この類型に対する行動変容側からの一つの回答である。ただし同研究は介入前後の比較を行っておらず、一旦停止行動の増加は測定されていない。したがって、行動変容アプローチが本類型に対して有効であるかは、現時点では未確定である。

### 5.3 停止率を引用する場合（要注記）

> 今田ら（2020）が報告した尼崎市での実証実験では、交差点での停止12,025回に対し不停止が48,667回であった（本研究による再計算では、交差点入域60,692回のうち停止は19.8%にあたる）。

⚠️ この文案を使う場合は、§3の問題点7（12,025という値が同論文p.1の事故統計と同一である）を確認したうえで採用すること。判別できない状態で停止率19.8%を本文に書くべきではない。
