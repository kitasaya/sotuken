## 4. 相互参照更新に使う方法

1. 上表の参照元ありファイルを、移動前→移動後の対応表で一括置換する。
2. 移動後、Git管理下のテキスト全体から旧ディレクトリ名・旧フルパス・移動対象の旧ファイル名参照を再検索する。
3. Markdownリンク、バッククォート内パス、通常文中の相対参照を別々に検査する。
4. 最後にMarkdown内のローカル参照候補を解決し、存在しないパスを0件にする。
