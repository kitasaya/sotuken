## 2. 2022年（令和4年）死亡・重傷事故の違反類型別内訳

母数は、自転車乗用者が第1当事者または第2当事者となった死亡・重傷事故 **7,107件**。参考資料2の総計円グラフを転記し、合計を再計算した。

| 類型 | 件数 | 全7,107件に対する割合（資料表示） |
|---|---:|---:|
| 信号無視 | 277 | 3.9% |
| 通行区分 | 116 | 1.6% |
| 横断・転回等 | 105 | 1.5% |
| 優先通行妨害等 | 131 | 1.8% |
| 交差点安全進行義務違反 | 916 | 12.9% |
| 徐行場所違反 | 100 | 1.4% |
| 一時不停止 | 572 | 8.0% |
| 自転車の通行方法違反 | 24 | 0.3% |
| 安全運転義務違反 | 2,730 | 38.4% |
| その他の違反 | 168 | 2.4% |
| 違反不明 | 62 | 0.9% |
| 違反なし | 1,906 | 26.8% |
| **合計** | **7,107** | **100.0%（丸め前の件数合計で検算）** |

第1当事者2,291件と第2当事者4,816件の内訳も同図にあり、合計は7,107件で一致する。法令違反ありは7,107−1,906＝**5,201件**で、73.18%となる。

## 3. 安全運転義務違反を除いた再計算

- 法令違反あり：5,201件
- うち安全運転義務違反：2,730件
- 安全運転義務違反を除く違反：5,201−2,730＝**2,471件**
- 全事故に対する割合：2,471÷7,107＝**34.77%**
- 違反あり5,201件に対する割合：2,471÷5,201＝**47.51%**

したがって、「約4分の3」のうち安全運転義務違反だけで全体の38.4%を占める。約4分の3から直ちに「ルート選択で回避できる違反が多い」と導くことはできない。

## 4. 指定された経路選択関連違反

| 求める類型 | 取得結果 | 注意 |
|---|---:|---|
| 通行禁止違反（8条1項） | **分離不能** | 参考資料2に独立項目がない。「その他の違反」168件等に含まれうるが、推定しない。 |
| 指定場所一時不停止等 | 572件（8.0%） | 図表ラベルは「一時不停止」。厳密な統計コード名との対応は元表データで追加確認余地あり。 |
| 信号無視 | 277件（3.9%） | 独立項目。 |
| 通行区分違反 | 116件（1.6%） | 図表ラベルは「通行区分」。 |

取得できた3類型の合計は965件、全7,107件の**13.58%**。通行禁止違反が分離できないため、4類型合計は算出不能である。

## 5. 2025年内訳の取得可否

警察庁ポータルには死亡・重傷事故の違反あり／なしの集約値が掲載されているが、5,375件を上記と同じ細分類へ分解した表は発見できなかった。別途公開されている2025年の法令違反別表は**自転車関連事故全体**の表であり、死亡・重傷事故7,125件の内訳ではないため、代用しない。

## 6. 2026年上半期の青切符運用状況

2026-08-26時点の警察庁報道発表一覧を確認したが、青切符については施行後1か月の公表（告知2,147件、指導警告票135,855件）が最新であり、上半期集計は未発見だった。

また、1か月資料は告知総数と指導警告票総数を示すが、**通行禁止違反の件数・構成比は公表していない**。

## 7. 論文での安全な文案

> 警察庁によれば、2022年に自転車乗用者が第1または第2当事者となった死亡・重傷事故7,107件のうち5,201件（73.18%）で自転車側に法令違反が認められた。ただし、このうち2,730件は安全運転義務違反であり、同違反を除くと2,471件（全体の34.77%）である。この統計は自転車側の法令違反が重大事故に広く関係する事実を示すが、ルート選択によって回避可能な違反の割合を直接示すものではない。
