# 分析：判定影響曖昧率（バッチ6）

**確認日：2026-08-26 ／ 対象：Google 15ルート・379判定点、Layer 2右折点23点**

## 1. 結論

閾値2.0mでは、幾何的曖昧点は188/379点（49.60%）だった。一方、第1候補と第2候補で「判定区分、`oneway` 生値、進行方向、自転車除外タグ」の組が変わる**判定影響曖昧点は150/379点（39.58%）**だった。

ただし、150点のすべてが「違反／非違反」の反転ではない。`oneway` の意味を正規化すると149/379点（39.31%）、本番判定関数が返す違反有無まで反転する点は12/379点（3.17%）である。したがって、49.60%だけを「違反判定が不安定な割合」と呼ぶのは過大である一方、3.17%だけを示すとタグ・対象範囲・方向判定の不安定性を隠す。三つを分けて報告する必要がある。

| 指標（閾値2.0m） | 件数 | 全379点比 |
|---|---:|---:|
| 幾何的曖昧 | 188 | 49.60% |
| 判定影響曖昧（`oneway` 生値を含む主指標） | **150** | **39.58%** |
| 判定影響曖昧（`oneway` を意味正規化） | 149 | 39.31% |
| 違反有無が反転 | 12 | 3.17% |

生値版と意味正規化版の差は1点だけで、浦和→さいたま新都心 sample 14 の `oneway` 未設定と明示的 `oneway=no` の差である。法的結果は同じだが、指示されたタグ値監査のため主指標には含めた。

## 2. 方法と再現条件

- 候補順位・距離：`services.overpass._rank_way_candidates` と `_point_to_way_dist_m`
- Layer 1判定：`scripts.route_match_probe.is_oneway_violation` 経由で、本番の `services.law_checker.check_oneway_violation` を使用
- 方向照合：本番の `services.law_checker._check_direction`
- Layer 2判定：本番の `services.law_checker.check_two_step_turn`
- ルート復号・40m間隔化・進行ベクトル：`services.external_route_scorer` の既存関数
- OSM固定入力：`graphhopper/kanto-260801.osm.pbf`、data date `2026-08-01T20:21:21Z`
- PBF SHA-256：`A14EC3138BC9BCDE57E778746D7121D9B1369DA36A7BE123662EC215F818E7AF`
- 実行スクリプト：`backend/scripts/analyze_decision_ambiguity.py`

分析スクリプト内で違反判定を再実装していない。判定区分は、本番関数の違反結果と、候補除外前の向き不整合、タグ状態を区別して分析用に付した。

比較組は次の4項目である。

1. `violation` / `legal_forward` / `legal_bicycle_exempt` / `out_of_scope_no_oneway` / `out_of_scope_axis_misaligned`
2. `oneway` タグ生値
3. 本番方向照合による `with` / `against` / `not_applicable`
4. `oneway:bicycle=no` または反対方向自転車レーンの有無

判定点ごとのway ID、タグ、マージン、両候補の判定は `backend/data/decision_ambiguity_points.csv` に全379点を保存した。`decision_impact_ambiguous_2m=True` の150行がA-2の全リストである。

## 4. 差の内訳

2.0m未満188点のうち、判定区分自体が異なるのは147点、`oneway` の法的意味が異なるのは65点、進行方向照合が異なるのは80点、自転車除外状態が異なるのは8点、違反有無が異なるのは12点だった。項目は重複するため合計は150にならない。

この結果は、「共有端点を持つ連続wayなら大半は同一判定になる」という仮説を**支持しなかった**。幾何的曖昧188点から判定影響150点への減少は38点（20.21%）にとどまる。OSMの連続wayでも、分割位置で `oneway`、道路種別、way軸方向が変わるためである。

## 6. 論文に使える記述案

> 判定点と第1・第2候補wayの距離差が2m未満となる幾何的曖昧点は379点中188点（49.60%）であった。さらに、候補選択により判定区分、onewayタグ、進行方向照合または自転車除外状態の少なくとも一つが変わる判定影響曖昧点は150点（39.58%）であった。一方、違反有無そのものが反転した点は12点（3.17%）であった。したがって、幾何的近接、判定属性の変化、違反結論の反転を区別して報告する。

限界3の更新案：

> OSMでは交差点やタグ変化位置でwayが分割されるため、単純な最近傍選択は候補間距離が僅差の地点で不安定になる。本データでは2m閾値で幾何的曖昧点が49.60%、判定属性まで変化する点が39.58%、違反有無が反転する点が3.17%であった。本システムは2m未満を判定不能として明示し、閾値感度を併記する。なおLayer 2でも右折点23点中3点（13.04%）で候補選択により案内要否が変化した。
