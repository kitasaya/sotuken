# R1 見逃し（FN）候補の抽出 — 一方通行

`ground_truth_template.csv` は検出された違反の行しか持たないため、Recall の分母
（見逃しの母集団）が存在しない。本レポートはその母集団を論理的に絞り込んで作る。

> 一方通行違反は `oneway=yes`（または `-1` 等）タグを持つ way 上でしか発生し得ない。
> したがって見逃し候補は「初期ルートが通った way のうち、`oneway` 系タグを持つが
> 違反として検出されなかったもの」に限定できる。

**この絞り込みの限界（重要）：** 「現地は一方通行だが OSM にタグがない」ケースは
この方法では抽出できない。これは限界1（RESEARCH.md 24.1節・A群6件）の裏返しであり、
**原理的に測定不能**である。したがって本レポートが与えるのは
**「タグ基準の Recall」であって現実基準の Recall ではない。** 論文で引用する際は
この条件を必ず併記すること。

## B. 母集団のサイズ

「延べ」は同じ way が別ペアで再登場した場合に別件として数えたもの、
「ユニーク」は way_id で重複を除いたもの。判定器はペアごとに独立して
判定するため、**Recall の母集団は延べの側**である。

| 項目 | 件数（延べ） | 件数（ユニーク） | 延べに対する割合 |
|---|---:|---:|---:|
| 初期ルートが通った way | 662 | 617 | 100.0% |
| うち `oneway` タグを持つ way | 254 | 238 | 38.4% |
| うち違反として検出された way | 1 | 1 | 0.2% |
| **FN候補（oneway あり・未検出）** | **253** | **237** | **38.2%** |

`oneway` way に対する検出率（内訳の確認用）: 1/254 = 0.4%

**この `oneway` way 254 件が Recall の分母（母集団）になる。**

## E. タグ基準 Recall の暫定値

**人手判定前なので確定値は出せない。** 下記は上下の幅を示すためのもの。

記号: D = 同一実行で検出された `oneway` 違反 way 数、U = `unknown`、S = `short_segment`、T = `tag_fetch_failed`。

- D = 1, U = 0, S = 0, T = 0

| 仮定 | 計算式 | Recall |
|---|---|---:|
| 最良（`unknown` は全て正しい非検出） | 1 / (1 + 0) | **1.000** |
| 最悪（`unknown` は全て真の見逃し） | 1 / (1 + 0) | **1.000** |
| 参考（要確認 0 件を全て見逃しと仮定） | 1 / (1 + 0) | 1.000 |

**この値の読み方（注意）：**

- 分子の D は「検出された件数」であり、**真陽性の件数ではない**。現地確認で偽陽性と判明した分だけ分子は下がる。R1 の Precision 側（現地確認済みの分類）を確定させてから改めて計算すること。
- 分母は **OSM に `oneway` タグがある way に限定**されている。「現地は一方通行だがタグがない」道（限界1・A群と同じ構造）は最初から母集団に入らないため、この Recall は現実基準の Recall の**上限側**に偏る。
- `bicycle_exempt` / `forward_travel` は「検出しないのが正しい」ケースなので、見逃しには数えていない（真陰性に相当する）。

## 付記：診断ロジックの出所

- 進行方向照合は `services/law_checker.py` の `_check_direction` を、ジオメトリのクリップは `services/route_analyzer.py` の `_trim_geometry` を**そのまま呼んでいる**（スクリプト側で再実装・近似していない）。
- way ごとの区間（`start_idx`〜`end_idx`）と travel_vector の作り方は`_analyze_v3` と同一。同じ way が複数区間に現れた場合に最初の区間のみを採用する規則も揃えてある。
- **方向情報は「なぜ検出されなかったか」の説明にのみ使い、マッチ候補の選択には使っていない**（循環論法の回避・RESEARCH.md 21.11節）。
- 検出された違反の way_id は過去の CSV ではなく**同一実行のレスポンス `violations[]`** から取っている（OSM 更新で値が変わるため）。
